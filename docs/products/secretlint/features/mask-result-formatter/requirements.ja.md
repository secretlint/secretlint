# mask-resultフォーマッター

[English](requirements.md)

## このドキュメントについて

`mask-result`フォーマッターは、ファイルの内容を、秘密情報を`*`に置き換えた状態で出力する。これにより、秘密情報を含めずに内容を共有したり保存したりできる。
親のProductは[Secretlint](../../product.ja.md)である。

### スコープ

- `mask-result`フォーマッターの出力
- `--output`でファイルをその場でマスクすること
- マスクできないファイル

### スコープ外

- メッセージ中の秘密情報の値のマスク。機能「結果の秘密情報のマスク」が扱う。
- フォーマッターの選び方と、コマンドの終了ステータス。[結果の出力](../result-output/requirements.ja.md)が扱う。

## ユーザーストーリー

### 秘密情報を含まない内容を得る

開発者として、シェルの履歴のようなファイルを共有したり残したりできるように、秘密情報をマスクしたファイルの内容がほしい。

**受け入れ条件:**

Scenario: ファイルに秘密情報がある場合、出力は秘密情報を`*`に置き換えた内容になる

- Given: 有効なルールが報告する値が、テキストファイルにある。
- When: 開発者が`--format=mask-result`を付けて、そのファイルに`secretlint`を実行する。
- Then: 標準出力はファイルの内容になり、報告された値の各文字は`*`に置き換えられている。それ以外の文字と内容の長さは、ファイルと同じである。

Scenario: ファイルに秘密情報がない場合、出力は内容そのままになる

- Given: 有効なルールが報告する値がないテキストファイルがある。
- When: 開発者が`--format=mask-result`を付けて、そのファイルに`secretlint`を実行する。
- Then: 標準出力は、変更のないファイルの内容になる。

Scenario: `--output`が同じファイルの場合、ファイルはマスクした内容に置き換わる

- Given: テキストファイル`.zsh_history`に秘密情報がある。
- When: 開発者が`secretlint .zsh_history --format=mask-result --output=.zsh_history`を実行する。
- Then: `.zsh_history`はマスクした内容になる。標準出力は空になる。

Scenario: 複数のファイルをlintした場合、出力はマスクした内容をlintした順につなげたものになる

- Given: 2つのテキストファイルをlintする。
- When: 開発者が`--format=mask-result`を付けて、それらのファイルに`secretlint`を実行する。
- Then: 標準出力は、1つ目のファイルのマスクした内容に、2つ目のファイルのマスクした内容が区切りなしで続いたものになる。

Scenario: バイナリファイルをlintした場合、コマンドは何も出力せずに失敗する

- Given: lintするファイルの1つがバイナリファイルである。
- When: 開発者が`--format=mask-result`を付けて、それらのファイルに`secretlint`を実行する。
- Then: 標準エラー出力に、バイナリファイルには対応していないことが表示される。マスクした内容は出力されない。終了ステータスは2になる。

Scenario: 空のファイルをlintした場合、そのファイルの出力は空で、コマンドは成功する

- Given: 空のファイルと、秘密情報のないテキストファイルをlintする。
- When: 開発者が`--format=mask-result`を付けて、それらのファイルに`secretlint`を実行する。
- Then: 標準出力は、テキストファイルの内容だけになる。終了ステータスは0になる。

## 機能要件

### マスクした出力

**概要:** lintした各ファイルの内容を、報告された値をマスクして出力する。

**入力:** `--format=mask-result`と、lintするファイルまたはSTDINの内容。

**出力:** lintしたすべてのファイルのマスクした内容を、1つのテキストにしたもの。

#### 適用する条件

報告された値とは、メッセージの範囲である。重大度にかかわらず、すべてのメッセージを使う。
範囲の各文字を1つの`*`に置き換えるので、内容の長さは変わらない。
メッセージの有無にかかわらず、lintしたすべてのファイルの内容を出力する。空のファイルは出力に何も加えない。
設定ファイルの問題のメッセージは、`mask-result`では出力しない。

##### 内容の種類ごとの振る舞い

| 内容の種類 | `mask-result`の出力 | 終了ステータス |
| --- | --- | --- |
| 秘密情報のあるテキストファイル | 報告された各値を`*`に置き換えた内容 | 重大度がエラーのメッセージがあれば1、なければ0 |
| 秘密情報のないテキストファイル | 内容そのまま | 0 |
| 空のファイル | なし | 0 |
| バイナリファイル | すべてのファイルについてなし。標準エラー出力に、バイナリファイルには対応していないことが表示される | 2 |
| STDINの内容 | 報告された各値を`*`に置き換えた内容 | 重大度がエラーのメッセージがあれば1、なければ0 |
| 問題のある設定ファイル | なし。設定についてのメッセージは出力しない | これらのメッセージでは変わらない |

`--output`を指定した場合、[結果の出力](../result-output/requirements.ja.md)のとおり、コマンドが終了ステータス2で失敗しないかぎり、終了ステータスは0になる。

#### 例外ケースでの振る舞い

##### バイナリファイル

コマンドはエラーで失敗し、すべてのファイルについて何も出力しない。
`mask-result`は基本的に1つのファイルに使うものなので、バイナリファイルはスキップせずエラーとして扱う。

## データ要件

### 必要なデータ

- **lintしたファイルの内容:** lintした各テキストファイルの、lintした時点の内容全体。1回の実行の間、lintしたすべてのファイルについて保持する。
- **メッセージの範囲:** 報告された各値の、内容の中での開始位置と終了位置。

### データ間の関係

各範囲は、同じファイルの内容を指す。

### 個人情報

収集しない。出力は、マスクした値を除いて、lintしたファイルと同じテキストを持つ。

## 依存する外部サービス

なし。

## セキュリティ上の留意事項

出力は、ルールが検査した内容でなければならない。出力がファイルの新しい内容だった場合、どのルールも検査していない秘密情報が、マスクされずに出力されうる。
有効なルールが報告しない値は、そのまま出力に残る。
